# 제작기·업데이트·문의 이메일 반영본

반영 내용:

- `/devlog/paper-soccer/` 제작기 추가
- `/updates/` 업데이트 기록 추가
- Google Analytics 연결 내용은 업데이트 기록에서 제외
- 문의 이메일 `retroplayground.help@gmail.com` 반영
- 개인정보처리방침 문의 이메일 반영
- 메인과 기존 페이지 메뉴 업데이트
- `sitemap.xml` 업데이트

## 배포

```bash
git pull origin main
git status
git add .
git commit -m "제작기와 업데이트 기록 추가"
git push
```
