# 홈 화면 딱지치기 버튼 추가

## 변경 내용

- 홈 첫 화면 소개 문구에 책받침 축구와 딱지치기를 함께 표시
- 첫 화면에 `딱지치기 시작` 버튼 추가
- 기존 `책받침 축구 시작`, `게임 둘러보기` 버튼 유지
- 모바일에서는 버튼이 자동으로 다음 줄로 배치
- 기존 Google Analytics와 AdSense 연결 코드 유지

## 배포

압축을 풀어 저장소 최상위에 전체 복사하고 덮어쓴 뒤 실행합니다.

```bash
git pull origin main
git status
git add -A
git commit -m "홈 첫 화면에 딱지치기 바로가기 추가"
git push
```

## 광고 관련

현재 홈 본문 최대 폭은 1080px입니다. 승인 후 AdSense 자동 광고의
`Side rail ads`를 켜면 충분히 넓은 데스크톱 화면에서 바깥 여백에
광고가 표시될 수 있습니다. 별도 고정 광고 칸은 아직 추가하지 않았습니다.
